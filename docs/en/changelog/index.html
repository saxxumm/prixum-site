What's new

Every Prixum Launcher version, newest first.

12.4.0 October 3, 2026 Latest version
On GitHub

What's new

  • Skins like in the Modrinth App. A large player on the left that you can turn with the mouse, with the model and cape next to it. All saved skins on the right, each one walking in place. Add a skin from a file, by drag and drop, by player name or by link: NameMC, a direct PNG, textures.minecraft.net. If the clipboard holds a NameMC skin link, the launcher offers to add it.
  • Skin history. For a Microsoft account the launcher loads the skins the account wore before from the public crafty.gg API and adds the new ones to your saved skins. It checks at most twice a day and never brings back skins you removed. Turn it off with the "Skin history" switch in the skins window.
  • Wallpaper behind the instances. Your own picture behind the instance list, the instance tiles turn into frosted glass. Blur and dimming are adjustable, with a preview right in the settings. Off by default: "Settings → Appearance → Wallpaper".
  • New settings. Pages are grouped, a search on top looks through every page and highlights what it finds (Ctrl+F), and each page has a short description under its title. Check boxes became switches, themes are picked from cards in their own colors, the accounts page got a button bar on top, and the window is larger.
  • Cat size, a slider in "Settings → Appearance → Cat".

Fixes

  • The launcher crashed when "Wear Skin" failed because of the network. Now a message appears and the skins window stays open.
  • Enter in the skins window no longer uploads a skin by accident.
  • Cape icons show in the list again.
  • The "General" tab on the Java page is translated.
12.3.0 October 2, 2026
On GitHub

What's new

  • New mod download window. Results are cards with an icon, the author, the download count and an "Add" button. On the right: the description, the version picker and links; collapse that panel with the "Details" button. Switch between Modrinth and CurseForge with the buttons on top, see what you picked at the bottom, then press "Download (N)". The windows for resource packs, shaders, texture packs and data packs look the same.
  • Instance editor. Mods, resource packs, shaders and data packs: "Download", "Check for updates" and "Add file" buttons on top, "All / Enabled / Disabled" filters, authors under the mod name, disabled mods in grey. Select several and "Enable", "Disable" and "Remove" appear. The "Version", "Worlds", "Servers" and "Screenshots" pages got a button bar on top too, and a card with the instance and its version sits on the left.
  • Shader hint. If an instance has neither Iris nor Oculus, the shaders page warns you and opens a search for the right mod.
  • Collapsible file list in the download window: the "Details" button leaves just the overall progress bar.
  • A proper Russian translation. Over 1400 strings reworded in plain language, plus strings that had no translation before.
12.2.0 September 30, 2026
On GitHub

What's new

  • New "Add Instance" window: the Minecraft version, the mod loader and mods in one place. The "Mods", "Resource packs" and "Shaders" buttons open Modrinth and CurseForge with only what fits the chosen version and loader, dependencies included. Everything you pick downloads right after the instance is created.
  • Ely.by accounts, "Settings → Accounts → Add Ely.by": sign in with a name or e-mail, two-factor protection supported, Ely.by skins and play on servers with Ely.by authentication through authlib-injector. Like offline accounts, it needs a Microsoft account that owns Minecraft.

Fixes

  • News in the launcher are no longer replaced by the old Prism feed copied over with your data
  • The add instance window opens large even if a small size was saved before
12.1.0 September 29, 2026
On GitHub

What's new

  • Prixum news: the news bar in the launcher shows Prixum Launcher releases, a click opens the release page
  • Less Prism: Prism Launcher's Discord, Matrix and Reddit are gone from the "Help" menu, and the logo now reads "Prixum Launcher"

Fixes

  • Strings that stayed in English are translated: "Loading news", "Total playtime", the color names in the theme editor, the "Scaling" tab in the settings
  • The "Last launched" text is no longer cut off in the sort box
  • The default window is larger, the right panel fits without scrolling
  • An instance's scaling settings stay inactive while the override is off
  • The theme editor tabs fit completely
12.0.0 September 29, 2026
On GitHub

The first release of Prixum Launcher.

What's new

  • Nova design: a sidebar, instance cards, a panel with play time and 7 built-in themes
  • Theme editor: colors, corner radius, sizes, the font and your own QSS with a live preview
  • Render scaling (Linux, through gamescope): a lower resolution with "sharp pixels", "smooth", AMD FSR and NVIDIA NIS filters
  • New icons in the settings and the instance editor
  • Moving over from Prism Launcher: on the first start you can copy instances, accounts and settings
