Часті питання

Не знайшов відповіді? Запитай у нашому Telegram, там відповідають.

Чим Prixum відрізняється від Prism Launcher?

Prixum зібраний з Prism Launcher і вміє все те саме: моди, модпаки з Modrinth і CurseForge, кілька акаунтів, завантаження Java. Зверху додано дизайн Nova з темами й редактором тем, вікно скінів як у Modrinth App, шпалери з матовим склом, нові налаштування з пошуком, масштабування рендера й акаунти Ely.by.

Це безкоштовно?

Так. Prixum безкоштовний, без реклами й реєстрації. Код відкритий на GitHub під ліцензією GPL-3.0.

Як перенести збірки з Prism?

Під час першого запуску Prixum сам запропонує скопіювати збірки, акаунти й налаштування з Prism Launcher. Копіювання займає хвилину, теку Prism він не чіпає, тож обидва лаунчери можна тримати поруч.

Windows пише, що застосунок може бути небезпечним. Що робити?

Збірки поки не підписані сертифікатом, тому Windows SmartScreen їх не впізнає. Натисни «Докладніше», потім «Однаково запустити». На macOS відкрий застосунок через правий клік і «Відкрити».

Чи потрібен куплений Minecraft?

Для гри потрібен акаунт Microsoft з купленим Minecraft. Після входу можна додати офлайн-акаунти й акаунти Ely.by, наприклад для серверів з його авторизацією.

Як змінити скін?

Відкрий меню акаунта внизу ліворуч і вибери «Скіни…». Скін додається файлом, перетягуванням, ніком гравця або посиланням з NameMC. Вибери скін і натисни «Вдягнути скін».

Як увімкнути шпалери за збірками?

«Налаштування → Зовнішній вигляд → Шпалери»: увімкни перемикач і вибери картинку. Там само налаштовуються розмиття й затемнення. За замовчуванням шпалери вимкнені.

Як оновити Prixum?

На Windows, в AppImage і portable-версії на Linux лаунчер сам перевіряє оновлення й пропонує встановити нову версію. На macOS і з пакетом для Arch завантаж нову версію зі сторінки «Завантажити».

Де лежать збірки й налаштування?

Windows: %APPDATA%\PrixumLauncher. Linux: ~/.local/share/PrixumLauncher. macOS: ~/Library/Application Support/PrixumLauncher. Portable-версія зберігає все у своїй теці. Швидко відкрити теку можна з меню «Теки» в лаунчері.

Масштабування рендера не працює

Масштабування працює на Linux через gamescope, його треба встановити: sudo pacman -S gamescope або sudo apt install gamescope. На Windows і macOS цієї функції немає.

Знайшов помилку. Куди писати?

Відкрий задачу на GitHub або напиши в Telegram. Якщо можеш, додай журнал з теки logs.
