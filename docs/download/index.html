Перед запуском

  • Сборки не подписаны. На Windows при первом запуске нажми «Подробнее», затем «Выполнить в любом случае». На macOS открой приложение через правый клик и «Открыть».
  • Portable-версия хранит сборки, аккаунты и настройки в своей папке, её можно носить на флешке.
  • Если версия для Windows не запускается, возьми сборку MinGW из списка всех файлов релиза.
  • На Arch и CachyOS пакет ставится командой sudo pacman -U prixumlauncher-12.4.0-1-x86_64.pkg.tar.zst.
  • Для масштабирования рендера на Linux нужен gamescope: sudo pacman -S gamescope или sudo apt install gamescope.
  • Для игры по сети нужен аккаунт Microsoft с купленным Minecraft. После входа можно добавить офлайн-аккаунты и Ely.by.
